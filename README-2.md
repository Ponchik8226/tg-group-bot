# tg-group-bot

Личный Telegram-бот для использования в группе с друзьями. Умеет ставить таймеры, хранить персональные быстрые кнопки и собирать статистику активности чата.

Написан на Python, задеплоен на **Render** (бесплатный тариф), база данных — **Neon** (PostgreSQL).

---

## Стек

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.12+ |
| Telegram API | pyTelegramBotAPI |
| База данных | PostgreSQL (Neon) |
| Хостинг | Render (Free Web Service) |
| Веб-сервер | Flask (webhook + healthcheck) |
| Мониторинг | UptimeRobot |

---

## Структура проекта

```
├── main.py          — пользовательские команды, middleware статистики, Flask, запуск
├── admin.py         — команды администраторов
├── database.py      — подключение к БД, таблицы, все запросы
├── config.py        — объект bot, переменные окружения, логирование
├── utils.py         — парсер времени, форматирование, упоминания, аптайм
└── requirements.txt
```

Новая пользовательская фича → `database.py` (если нужна БД) + `main.py`.  
Новая админ-фича → `database.py` + `admin.py`.  
`config.py` и `utils.py` трогаются редко.

## Переменные окружения

Задаются в **Render → Environment**:

| Переменная | Обязательна | Описание |
|------------|-------------|----------|
| `BOT_TOKEN` | ✅ | Токен от @BotFather |
| `DATABASE_URL` | ✅ | Pooled connection string от Neon |
| `ADMIN_IDS` | ✅ | Telegram ID администраторов через запятую |
| `WEBHOOK_URL` | ✅ | URL сервиса на Render (без `/webhook`) |
| `PORT` | — | Порт Flask, по умолчанию `10000` |

> Если `WEBHOOK_URL` не задан, бот запускается в режиме polling — удобно для локальной разработки.

Узнать свой Telegram ID — отправить боту `/id` в личке.

## База данных

Таблицы создаются автоматически при первом запуске (`database.init_db()`).

| Таблица | Что хранит |
|---------|------------|
| `timers` | Активные таймеры; переживают перезапуск бота |
| `users` | Пользователи, которых бот видел |
| `chats` | Чаты, где присутствует бот |
| `user_chat_stats` | Счётчики активности каждого пользователя в каждом чате |
| `user_buttons` | Персональные быстрые кнопки пользователей |

## Команды

### Таймеры

| Команда | Описание |
|---------|----------|
| `/т [время] [описание]` · `/t` | Установить одноразовый таймер |
| `/тр [интервал] [описание]` · `/tr` | Повторяющийся таймер — срабатывает снова и снова |
| `/mytimers` | Список активных таймеров с сортировкой и обновлением |
| `/del [ID]` · `/cancel` · `удалить` · `отмена` | Удалить таймер |

**Формат времени** — русские и английские единицы, можно комбинировать:

```
д / d — дни        ч / h — часы
м / m — минуты     с / s — секунды

Примеры: 1д5ч30м   2h30m   10с   45s
```

**Повторяющийся таймер** автоматически завершается: суммарный период не превышает 1 года.

### Быстрые кнопки

Персональные кнопки в панели ввода — видны только тебе (`selective=True`).

| Команда | Описание |
|---------|----------|
| `/к [название]` | Добавить одну или несколько кнопок |
| `/ук [номер или название]` | Удалить одну или несколько кнопок |
| `/ук все` | Удалить все кнопки |
| `/кнопки` · `/buttons` · `Кнопки` | Список кнопок с возможностью вкл/выкл |
| `/кнопки вкл` · `/кнопки выкл` | Включить или выключить отображение кнопок |

Добавление нескольких кнопок за раз:
```
/к Почта; Задачи; Позвонить      ← через «;»

/к Почта                          ← с новой строки
Задачи
Позвонить
```

Удаление нескольких:
```
/ук 1 3 5          ← по номерам через пробел
/ук Почта; Задачи  ← по названию через «;»
```

Максимум **20 кнопок**, название до **50 символов**.

### Прочее

| Команда | Описание |
|---------|----------|
| `/start` · `/help` | Интерактивная справка по разделам |
| `/ping` | Round-trip до Telegram API + uptime бота |
| `/id` | ID чата; реплаем — ID пользователя или бота |

### Админ-команды

Только в личке, только для ID из `ADMIN_IDS`.

| Команда | Описание |
|---------|----------|
| `адмхелп` | Список всех админ-команд |
| `стата` / `статистика` | Общая статистика бота |
| `топ вся` | Глобальный топ по всем чатам (пагинация ◀️▶️) |
| `топ [название или ID чата]` | Топ пользователей конкретного чата |
| `юзер [ID или @username]` | Статистика конкретного пользователя |

## Технические детали

### Таймеры

Реализованы через `threading.Timer` — не блокируют polling/webhook.  
Сохраняются в БД при создании, удаляются при срабатывании или отмене.  
При перезапуске восстанавливаются из БД — если таймер должен был сработать пока бот был выключен, он срабатывает сразу с пометкой об опоздании.  
Дополнительный поллер (каждые 30 сек) служит страховочной сетью.

Поддерживаются **Forum-топики** (тематические группы): уведомление таймера приходит именно в тот топик, где он был создан.

### Быстрые кнопки

`ReplyKeyboardMarkup` с флагом `selective=True` — кнопки видны только тому пользователю, который их создал. Остальные участники чата видят обычную клавиатуру ввода.

### Статистика

Middleware перехватывает каждое входящее сообщение и пишет счётчики в БД в фоновом потоке, чтобы не задерживать ответ бота. Считаются: сообщения, символы, стикеры, фото, видео, голосовые/кружки, GIF, пересылки.

Для работы в группах необходимо отключить Privacy Mode:  
`@BotFather → /mybots → Bot Settings → Group Privacy → Turn off`

### Inline-кнопки — защита от чужих

Все inline-кнопки (сортировка таймеров, вкл/выкл кнопок, разделы справки) проверяют, что нажавший — автор оригинальной команды. Попытка нажать чужую кнопку получит тихий алерт без изменения данных.

### Отказоустойчивость

- Polling обёрнут в `while True / try-except` с перезапуском через 5 сек.
- Подключение к БД — пул с автовосстановлением при обрыве SSL (Neon засыпает через 5 мин).

## Деплой с нуля

1. Создать бота через @BotFather, получить токен.
2. Отключить Privacy Mode: `@BotFather → /mybots → Bot Settings → Group Privacy → Turn off`.
3. На [neon.tech](https://neon.tech) создать проект, скопировать **pooled** connection string.
4. Загрузить файлы в GitHub-репозиторий.
5. На [render.com](https://render.com) → **New → Web Service** → подключить репозиторий:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
   - **Instance Type:** Free
6. Добавить переменные окружения (`BOT_TOKEN`, `DATABASE_URL`, `ADMIN_IDS`, `WEBHOOK_URL`).
7. После деплоя написать боту `/id` в личке — должен вернуть твой Telegram ID.
8. Настроить [UptimeRobot](https://uptimerobot.com): HTTP-монитор на `https://<your-render-url>/`, интервал 5 минут.

## Бесплатный хостинг — нюансы

**Render** даёт 750 бесплатных часов в месяц на воркспейс. Одного бота хватает на полный месяц.

**Neon** — база "засыпает" после 5 минут без запросов. Первый запрос после паузы добавляет ~300–500 мс (cold start). Пул соединений автоматически переподключается.

**UptimeRobot** не даёт сервису на Render засыпать, но от плановых перезапусков самого Render не защищает. При перезапуске активные таймеры восстанавливаются автоматически.
